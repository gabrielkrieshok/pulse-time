How to read it

Terse — nearest 15 minutes

Hours first: each long is 5 hours, each short is 1 hour. Pause. Then each long is a quarter hour (none means it is before :15).

7:20 → long, short, short · pause · long.

Digits — exact minute

Hours, then minutes. In each group, longs are the tens digit and shorts are the ones digit. No minute group means it is exactly on the hour.

12:47 → long, short, short · pause · long ×4, short ×7.

Morse — each digit in Morse code

Every digit is exactly five buzzes (long = dash, short = dot). Pauses separate digits. The hour’s leading zero is skipped.

3:05 → ...-- · ----- · .....

Tips for learning

Start on Terse with the Learn vibe (slow, wide gaps). Turn on the hourly chime so you get free practice at a moment you can check against a clock. Move to Standard once you stop counting.
